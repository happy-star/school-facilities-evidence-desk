# Data notice

The public demo uses `fixtures/synthetic/`. Those numbers are invented sample rows. They are not UDISE+ 2022–23 statistics and they are not official India figures. The interface, answers, and CSV/JSON export say so.

The historical booklet is one 2022–23 report. This tree does not contain that PDF, a bulk extract, or official cell values. Statistical year labels in the reader mean 2022–23, not the PDF file's creation date, and not a 2026 condition.

The MIT licence covers source code written for this project. It does not cover the booklet or official statistics. No redistribution permission for the booklet is established here, and none is granted.

The citation of the booklet remains in the application source so the disabled importer still knows which file it would have refused. That citation is not a copy of the file.
