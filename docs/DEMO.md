# Demo

Live demo: http://140.82.0.23:8893/ (HTTP, not HTTPS).

Repository: https://github.com/happy-star/school-facilities-evidence-desk

1. Open the desk. **Official import** is selected and the table is empty. No percentage is invented.
2. Select **Synthetic sample**. Read the banner. It says the rows are synthetic sample data, not official India statistics, and that the official import was not replaced.
3. Leave **Deterministic baseline** selected. Ask for Kerala, functional girls toilets, all management, 2022–23. The answer quotes the invented sample value and says `SYNTHETIC TEST DATA`.
4. Ask whether building toilets caused enrolment to rise. The answer refuses and does not quote a sample percentage.
5. Export CSV or JSON. The file name starts with `synthetic-sample-not-government`, and the metadata repeats the sample notice.
6. Switch back to **Official import**. The sample leaves the screen. The official view is empty again.

**Reviewed plan** is optional. It is a post-review edit, not the unedited IDE file. PDF upload is not available in this build.
